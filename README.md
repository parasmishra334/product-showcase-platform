## 📌 Project Overview
**ShowCase** is a modern, responsive, frontend-only product catalog and showcase web platform built with semantic HTML5, CSS3, and vanilla JavaScript (ES6+). It enables businesses to display products with rich multimedia galleries, live search, multi-faceted filtering, side-by-side product comparisons, persistent wishlist, verified reviews, 360-style interactive demos, and a comprehensive admin management control deck—all powered by `localStorage` without requiring any backend server or database.

---

## 🚀 Key Features

- **Sticky Navigation with Mega-Menu:** Multi-column dropdown categories showcasing subcategories and icons.
- **Product Catalog & Filtering:** Real-time search, multi-category, brand, price slider, rating, stock status filters, and sorting (Price, Rating, Newest, Name).
- **Product Detail View:** Multi-image gallery carousel, technical specifications table, verified reviews, and related recommendations.
- **Product Comparison Matrix:** Up to 3 products side-by-side with visual highlights for lowest price and highest rating.
- **Wishlist & Recently Viewed:** Stored in `localStorage` with real-time badge updates.
- **Interactive 360 Demo Page:** Color & finish customizer with embedded video walkthroughs.
- **Role-Based Admin Dashboard:** Product CRUD modal, reviews moderation, customer inquiry tracking, pure CSS analytics charts, CSV and print-ready PDF export.
- **Dark Mode Support:** Smooth purple accent theme switch saved across sessions.
